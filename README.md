# Wavelet-Based Low-Frequency Enhancement for Ultrasound Medical Image Segmentation

This repository accompanies the paper **"Wavelet-Based Low-Frequency Enhancement for Ultrasound Medical Image Segmentation."**

## Datasets

The experiments in the paper use four publicly available ultrasound datasets. Please obtain each dataset from its original source, follow its applicable license and terms of use, and cite the corresponding dataset publication.

| Dataset | Task | Official access |
| --- | --- | --- |
| DDTI | Thyroid nodule segmentation | [CIMA Lab / Universidad Nacional de Colombia](https://cimalab.unal.edu.co/software/detail/2) |
| TN3K | Thyroid nodule segmentation | [TRFE-Net official repository](https://github.com/haifangong/TRFE-Net-for-thyroid-nodule-segmentation) |
| BUSI | Breast lesion segmentation | [Original dataset page](https://scholar.cu.edu.eg/?q=afahmy/pages/dataset) or [Kaggle mirror](https://www.kaggle.com/datasets/aryashah2k/breast-ultrasound-images-dataset) |
| BUS-BRA | Breast lesion segmentation | [Zenodo record](https://zenodo.org/records/8231412) |

For the BUSI experiments in this work, the dataset was cleaned following the reported audit of duplicated and discrepant cases before splitting. The cleaning rules and split files will be provided with the code.

## Notes

- No dataset images or annotations are redistributed in this repository.
- Please cite the original dataset papers when using these datasets.
